# <u>Preface</u>

One sentiment that I have carried, and forever will continue to carry, is that anyone can do math. All it takes is proper intuition and the exposure to tools that can turn said intuition into rigor. That is my intention, to possibly spark intuition in those who might otherwise be scared off by the abstractions of topology. This is intended to cover general/point set topology at an undergraduate level. While there are no strict prerequisites, topology invokes a number of mathematical branches including, but not limited to, set theory, abstract & linear algebra, geometry, and quite a bit of real analysis. Because of this, an understanding of mathematical logic is recommended. If you feel that this excludes you in some way, please do not worry! Mathematics is hard for most, and it will knock you down on occasion. But please, pick yourself back up because I know you are more than capable. Remember, anyone can do math.
